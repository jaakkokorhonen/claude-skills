# Contributing to claude-skills

Thank you for your interest in contributing. This document covers the
requirements and conventions for submitting new skills or improving existing
ones.

## Skill structure

Each skill lives in its own subdirectory under `skills/`:

```
skills/<skill-name>/
├── SKILL.md          # Required — frontmatter + instructions
├── scripts/          # Optional — helper scripts (Python, Bash)
├── docs/             # Optional — reference documentation
├── references/       # Optional — supplementary material
└── examples/         # Optional — worked examples
```

### `SKILL.md` frontmatter

Every `SKILL.md` must begin with a YAML frontmatter block:

```yaml
---
name: my-skill-name          # lowercase, hyphenated, unique across repo
description: >-
  One or two sentences in third person describing when an agent should
  activate this skill. Be specific — vague descriptions cause missed
  activations.
---
```

The `description` field is the most important field. Write it as a precise
trigger condition, not a feature list.

### Python scripts

- Use `uv` inline script metadata (`# /// script`) for dependency declarations.
- Do **not** require a pre-existing virtual environment or `pip install` step.
- Target Python ≥ 3.10.
- Add the Apache-2.0 copyright header at the top of every `.py` file:

## Secret scanning

Before opening a PR, verify that no secrets are committed:

```bash
# Quick grep for common patterns
grep -rE '(api_key|secret|password|token)\s*=\s*["\x27][^"\x27]{8,}' skills/
```

Placeholder strings like `api_key="your-api-key-here"` are acceptable.
Real credentials are not, regardless of whether they are still active.

The CI pipeline (if configured) will run secret scanning automatically.

## Pull request checklist

- [ ] `SKILL.md` has valid frontmatter (`name`, `description`).
- [ ] All Python files include the Apache-2.0 copyright header.
- [ ] No secrets, tokens, or credentials are present.
- [ ] `LICENSE-SKILLS.md` is updated if the skill has a copyright holder other
      than Jaakko Korhonen (e.g. upstream Google LLC scripts).
- [ ] The skill directory name matches the `name` field in `SKILL.md`.
- [ ] README category list is updated if the skill belongs to a new category.

## AI-generated contributions

AI-assisted contributions are welcome. When a skill or script was substantially
generated by an AI tool (Claude Code, Gemini, Copilot, etc.), add a co-author
trailer to the commit message:

```
Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
```

This is already the practice established in the initial commit of this
repository. The human author remains responsible for reviewing, testing, and
asserting the licensing of AI-generated content before submission.
