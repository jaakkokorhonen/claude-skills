# claude-skills

A snapshot of Claude Code skills available in this environment — packaged instructions covering everything from bioinformatics database queries to GCP data pipelines, web development, and Claude Code / Antigravity workflows.

Each subdirectory under `skills/` is a self-contained skill with its own `SKILL.md` describing when and how it applies.

## Categories

- **Bio/life-sciences tooling** — AlphaFold, AlphaGenome, ChEMBL, ClinVar, dbSNP, Ensembl, GTEx, PubMed, UniProt, and more
- **GCP / data pipelines** — BigQuery, Dataform, dbt, Dataflow, Cloud Composer, Spark on Dataproc
- **Web / frontend** — accessibility debugging, Chrome DevTools, Chrome extensions, LCP optimization, modern web guidance, data visualization
- **Claude Code / Antigravity** — Claude API reference, Artifacts, config, keybindings, code review, workflows
- **Anthropic skills bundle** — docx, pdf, pptx, xlsx, memory consolidation, scheduling
- **Other** — credentials handling, doc validation, link checking, Python dependency management, versioning
